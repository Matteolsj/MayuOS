# MayuOS

MayuOS is an experimental operating system built from scratch,
powered by the Mayu programming language.

## Projects

- **Mayu** — A statically typed systems programming language.
- **MayuOS** — An operating system developed primarily in Mayu and assembly.

## Status

Early development.

## Architecture

- Development host: macOS ARM64
- Initial target: x86-64
- Bootloader: Limine (planned)
- Kernel: Mayu + Assembly (planned)
